================================================================================
                         REQUIRED SETUP (5 MINUTES)
================================================================================

STEP 1: Create Docker Hub Token
  1. Visit: https://hub.docker.com/settings/personal-access-tokens
  2. Click "Generate New Token"
  3. Name: "GitHub Actions CI/CD"
  4. Permissions: Read/Write
  5. Copy the token

STEP 2: Add GitHub Secrets
  1. Go to: https://github.com/WordSpring/ikutibnb_backend
  2. Settings → Secrets and variables → Actions
  3. Add these secrets:
     - DOCKER_USERNAME: your-docker-username
     - DOCKER_PASSWORD: <token-from-step-1>
     - DOCKER_EMAIL: your@email.com

  Optional (for Kubernetes):
     - KUBE_CONFIG: base64-encoded kubeconfig
     - POSTGRES_USER: baby
     - POSTGRES_PASSWORD: $inbad1

STEP 3: Test the Pipeline
  1. Make a small change to your code
  2. Commit and push: git push origin develop
  3. Go to Actions tab → watch the workflow run
  4. Check logs for any errors

================================================================================
                         MONITORING & TROUBLESHOOTING
================================================================================

View Pipeline Status:
  → GitHub: Actions tab in your repository
  → Docker Hub: https://hub.docker.com/r/yourusername/ikutibnb-backend
  → Terminal: git log --oneline

Common Issues:

1. Tests fail in CI
   → Run locally: ./mvnw clean test
   → Check database connection in tests
   → Review test output in GitHub Actions

2. Docker push fails
   → Verify Docker Hub token and permissions
   → Check Docker is logged in: docker login
   → Ensure username matches secret

3. Kubernetes deployment fails
   → Check kubeconfig is correct
   → Verify cluster connectivity
   → Check pod logs: kubectl logs <pod-name> -n spring-app
   → Describe deployment: kubectl describe deployment springboot-app -n spring-app

4. Application won't start
   → Check environment variables
   → Verify database connection
   → Check health endpoint: curl http://localhost:8081/actuator/health
   → Review logs: docker-compose logs or kubectl logs
